# home-dashboard

Marc de fotos Android (Xoro CPF 10PF, Allwinner A133) convertit en dashboard familiar. Treballem des de WSL2.
Basat en <https://github.com/wesbos/photo-frame-dashboard> (clon a `~/photo-frame-dashboard`).

Fase 1 (només lectura): [WSL + USB](docs/wsl-setup.md) → `scripts/identify.sh` → [backup](docs/backup.md).
Regla: res d'escriptura al dispositiu fins tenir un backup verificat. `backups/`, `diagnostics/`, `frames/` són privats i ignorats.
